# PROYECTO_INDIVIDUAL

# Planificador de Tareas

Aplicación web desarrollada como parte del proyecto individual del bootcamp para la gestión eficiente de tareas diarias, organizada mediante interfaces limpias y componentes reutilizables.

## Tecnologías Utilizadas

* **HTML5** - Estructura semántica de la aplicación.
* **CSS3 & Bootstrap 5** - Estilos personalizados, sistema de rejillas y diseño responsivo.
* **JavaScript** - Lógica de la aplicación e interactividad (próximamente).
* **Git y GitHub** - Control de versiones y repositorio remoto.

---

## Características Principales

* **Estructura de Dos Columnas:** Visualización clara dividida entre la lista de tareas y el formulario de registro.
* **Filtros Avanzados:** Opciones para buscar tareas por texto, estado, prioridad, categoría y fecha.
* **Diseño Personalizado:** Interfaz adaptada con componentes modernos y accesibles de Bootstrap.
